# Rights-Aware Transformation

Use this reference when source rights are unclear or the user requests an original work inspired by broad themes.

Faithfully adapt only user-authored, licensed, or public-domain material. Do not treat renaming characters or lowering textual similarity as permission to copy protected plot expression.

When the source is a protected third-party work and authorization is absent, do not preserve its distinctive sequence of events, characters, setting, or signature scenes. Offer a summary or create a genuinely new premise using only broad genre conventions.

## Original Transformation

Create a new work by changing:

- Names and titles.
- Worldbuilding labels.
- Relationship labels.
- Scene location and props.
- Order of non-essential events.
- Conflict wrapper.
- Dialogue wording.
- Signature visual moments.

You may preserve only high-level, non-distinctive elements such as:

- Emotional function.
- Broad genre promise.
- Viewer satisfaction curve.
- Episode-level conflict and payoff.

## Transformation Levels

### Close Adaptation

- Use only for user-authored, licensed, or public-domain source material.
- Preserve plot and roles while changing production form.

### Theme-Inspired

- Build new characters, setting, conflict progression, and scenes.
- Retain only a broad theme, genre promise, or emotional question.

### Premise-Independent

- Start from the user's desired audience, genre, and emotional payoff.
- Do not use protected source-specific characters, scenes, or plot sequence.

Ask about source authorization when it determines whether close adaptation is appropriate.
