# aitalk.cloud 沙雕动画小助手插件使用说明

> 插件版本：3.0.0  
> 适用平台：Windows  
> 适用软件：Adobe Animate 2020 或更高版本

## 一、插件简介

“aitalk.cloud 沙雕动画小助手插件”是一款 Adobe Animate 批量导出工具，可扫描 FLA 当前帧中的元件、组、位图和文本，并按指定层级、尺寸和目录结构导出 PNG 图片或 PNG 序列。

主要功能：

- 扫描当前帧中的可导出元素；
- 按元素类型筛选、全选或单独选择；
- 展开嵌套元件，按一级、二级或三级结构导出；
- 导出单张 PNG 或动画 PNG 序列；
- 为动画关键帧创建独立文件夹；
- 按原始大小、缩放比例或自定义尺寸导出；
- 显示导出进度，并支持中途取消。

## 二、安装插件

### 1. 解压安装包

将 `aitalk.cloud沙雕动画小助手插件.zip` 完整解压到一个普通文件夹中。

解压后应至少包含：

```text
aitalk.cloud沙雕动画小助手插件.zxp
一键安装.bat
tools/
  install_plugin.ps1
```

请勿只从压缩包中单独运行批处理文件，也不要移动或删除上述文件。

### 2. 运行一键安装

1. 关闭 Adobe Animate。
2. 双击解压目录中的 `一键安装.bat`。
3. 等待窗口显示“安装成功”。
4. 按提示关闭安装窗口，然后重新启动 Adobe Animate。

安装程序不需要管理员权限。它会自动：

- 为当前 Windows 用户开启 Adobe CEP 调试模式；
- 删除并替换本机已安装的旧版本；
- 将插件安装到：

```text
%APPDATA%\Adobe\CEP\extensions\com.FunnyAnimationAssistant.exporter.panel
```

### 3. 打开插件

启动 Adobe Animate，在菜单栏中选择：

```text
窗口 → 扩展 → aitalk.cloud沙雕动画小助手插件
```

插件将以面板形式打开，可将面板停靠到 Animate 工作区中。

## 三、导出前准备

1. 在 Adobe Animate 中打开需要处理的 `.fla` 文件。
2. 将时间轴播放头移动到包含待导出内容的帧，通常为第 1 帧。
3. 确认需要导出的图层处于可见状态。
4. 对散落的形状执行以下任一操作：
   - 按 `F8` 转换为元件；
   - 按 `Ctrl+G` 组合成组。

插件支持元件（Symbol）、组（Group）、位图（Bitmap）和文本（Text）。散落的形状（Shape）不会直接出现在扫描结果中；引导层、遮罩层和隐藏图层也会被自动忽略。

## 四、基本使用流程

### 第 1 步：扫描舞台

在“用户操作”页签中点击“扫描舞台”。插件会扫描当前帧，并在面板下方显示元素树。

如果修改了舞台内容或切换了时间轴帧，请重新点击“扫描舞台”。

### 第 2 步：选择导出内容

- 勾选需要导出的元素；
- 使用“全选”或“全不选”快速调整选择；
- 使用元件、组、位图、文本筛选按钮显示或隐藏对应类型；
- 点击树节点左侧的箭头，展开或折叠嵌套结构；
- 点击元件名称，可尝试进入该元件的编辑模式以便检查内容。

类型筛选只影响列表显示，不等同于转换或删除舞台内容。

### 第 3 步：选择输出路径

点击“浏览...”，选择 PNG 文件的输出根目录。建议使用一个空目录，方便检查和整理导出结果。

### 第 4 步：设置导出层级

- **导出一级元件**：导出舞台上所选元素本身。适合背景、道具、整个人物或无需拆分的素材。
- **导出二级元件（默认）**：导出所选元素内部的第一层子元素。适合将人物拆分为头、身体、手臂、腿等部位。
- **导出三级元件**：继续深入一层，适合结构更复杂的嵌套角色或素材。

层级越深，生成的部件和文件夹通常越多。首次使用建议先用少量素材试导出。

### 第 5 步：设置动画与尺寸

“为动画关键帧创建文件夹”：

- 勾选：为动画关键帧段建立子文件夹；
- 取消勾选：将动画帧平铺到对应输出目录。

缩放选项：

- **原始大小**：按素材原始尺寸导出；
- **缩放比例**：可选择 5%～5000%，缩放结果会直接烘焙到图片中；
- **自定义大小**：输入目标宽度和/或高度，插件按目标尺寸导出。

高倍率、超大尺寸或长动画会明显增加导出时间和内存占用。

### 第 6 步：执行导出

点击“导出选中元件”。面板会显示当前进度，完成后给出成功数量提示。

导出过程中可点击“取消”中止任务。取消前已经生成的文件可能会保留在输出目录中。

## 五、导出结果示例

假设舞台上有一个 `Character` 元件，内部包含多帧的 `Head` 和单帧的 `Body`。

一级导出可能得到：

```text
输出目录/
  Character/
    1.png
    2.png
    3.png
```

如果 `Character` 只有一帧，则可能直接生成：

```text
输出目录/
  Character.png
```

二级导出可能得到：

```text
输出目录/
  Character/
    Head/
      1.png
      2.png
      3.png
    Body.png
```

实际文件名和目录结构取决于 FLA 中的元件名称、嵌套层级、帧数及导出选项。

## 六、AI 自动化页签

“AI 自动化”页签用于显示本机 Bridge 服务、外部工具连接、当前任务、最近命令和连接日志。

普通手动导出不需要启用此功能。如果没有配套的本机 Bridge 服务或外部自动化工具，请保持“允许外部工具控制”未勾选；这不会影响“用户操作”页签中的扫描和导出功能。

## 七、常见问题

### 1. Animate 的“窗口 → 扩展”中找不到插件

请依次检查：

1. 确认安装窗口最后显示“安装成功”；
2. 完全退出并重新启动 Adobe Animate；
3. 确认 Animate 版本为 2020 或更高版本；
4. 检查以下文件是否存在：

```text
%APPDATA%\Adobe\CEP\extensions\com.FunnyAnimationAssistant.exporter.panel\CSXS\manifest.xml
```

若文件不存在，请重新解压完整安装包并再次运行 `一键安装.bat`。

### 2. 双击“一键安装.bat”后提示找不到安装包

说明解压后的目录结构不完整。请确保 `.zxp`、`一键安装.bat` 和 `tools` 文件夹位于同一个解压目录中，然后重试。

### 3. Windows 阻止运行安装文件

如果确认安装包来源可信，可在 Windows 安全提示中选择“更多信息”，再选择“仍要运行”。部分安全软件也可能拦截批处理或 PowerShell 脚本，需要将本安装包加入信任后重试。

### 4. 扫描不到某些内容

- 将播放头移到真正包含素材的帧；
- 确认图层未隐藏；
- 将 Shape 转换为元件或组；
- 修改舞台后重新点击“扫描舞台”。

### 5. 导出的素材缺少部位

- 展开元素树并确认对应子元素已勾选；
- 尝试将导出层级由一级改为二级或三级；
- 检查目标部位是否位于隐藏层、遮罩层或引导层；
- 确认元件和部位名称清晰且尽量不要重复。

### 6. 导出速度较慢

高倍率缩放、大尺寸位图、较深的嵌套层级和长动画序列都会增加导出时间。可减少所选元素或帧数、降低缩放比例，并先用单个角色测试。

### 7. 导出失败或结果异常

建议按以下顺序排查：

1. 将 FLA 文件保存后重试；
2. 选择本地磁盘上的空目录作为输出目录；
3. 避免使用无写入权限的系统目录；
4. 用单个元件、原始大小、一级导出进行最小化测试；
5. 关闭并重启 Adobe Animate 后重新扫描和导出。

## 八、更新与卸载

### 更新

关闭 Adobe Animate，解压新版安装包并再次运行 `一键安装.bat`。安装程序会自动删除旧版本并安装新版。

### 卸载

1. 关闭 Adobe Animate。
2. 在文件资源管理器地址栏输入：

```text
%APPDATA%\Adobe\CEP\extensions\
```

3. 删除文件夹：

```text
com.FunnyAnimationAssistant.exporter.panel
```

4. 重新启动 Adobe Animate。

卸载插件不会删除 FLA 源文件，也不会自动删除之前导出的 PNG 文件。
